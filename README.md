# Double Shot Camera (Android)

## Features
- Capture the first photo, then the second photo.
- Switch between rear and front camera between shots.
- Automatically combine the two photos horizontally (left + right).
- Save the combined JPEG in Gallery under Pictures/DoubleShotCamera.

## Build
1. Install Android Studio (latest stable).
2. Choose **Open** and select this `DoubleShotCamera` folder.
3. Let Gradle sync finish.
4. Connect an Android phone with USB debugging enabled, or use an emulator with camera support.
5. Press **Run**.

The first launch asks for camera permission. No account or internet connection is required by the app itself. Gradle needs internet once to download AndroidX CameraX dependencies.
